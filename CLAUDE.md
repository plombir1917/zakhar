# !захар — личное дело

Личный сайт-бренд Захара: не визитка, а картонная папка «Личное дело» на
столе. Открываешь обложку — внутри анкета, разделы на цветных закладках,
вещдоки-проекты, а красная бумажка «НЕ ТРОГАТЬ» включает тяжёлый режим
DJ Снюфа.

**Комментарии и тексты — по-русски.** Сайт только на русском.

## Решения владельца (7 октября 2026)

- Цель — личный бренд, главное действие — написать в Telegram
  (`https://t.me/plombir1917`). Других способов связи на сайте не предлагаем.
- Бренд — `!захар`. Место работы называем только «администрация региона».
- Метафора: основа — «личное дело»; документация (раздел «Код») и
  «тяжесть» (режим Снюфа) — вставки, а не основа. Сайт обязан быть
  дружелюбным обывателю: подписи закладок — простые слова.
- **Никакого ИИ-слопа**: рукописно, самобытно, видна ручная работа. Не
  кремовый фон с терракотой, не чёрный с кислотным акцентом, не одинаковые
  карточки с тенью, не «каждый блок выезжает при прокрутке».
- Треки с площадок на сайт не тянем — основные в Telegram-канале
  «документация к жизни», туда и ведём.
- Тяжёлое допустимо, но только в режиме Снюфа: основной режим лёгкий.

## Устройство

```
app/components/Dossier.vue     стол, папка, обложка, опись, закладки, листание
app/components/SnuffMode.vue   режим DJ Снюфа: прожекторы (canvas), бит (Web Audio)
app/components/pages/          листы дела: Анкета, Сцена, Код, Ивенты, Музыка, Личное, Связь
app/components/bits/           предметы: пометка ручкой, штамп, скрепка, скотч, каракули, набросок
app/data/dossier.ts            ВСЕ тексты, ссылки и факты — править здесь
app/assets/css/main.css        материалы (цвета), шрифты, общие стили листов
public/evidence/               скриншоты проектов для вещдоков
sources/                       сырьё от владельца (в git — только README)
```

Одна страница, разделы — якоря (`#scena`): открытая по ссылке на раздел папка
пропускает анимацию обложки.

Шрифты локальные (fontsource): Shantell Sans — рукопись (переменный, оси
INFM/BNCE дают «живую» руку), PT Mono — машинка, Golos Text — текст,
Ruslan Display — штампы.

## Ловушки

- **`perspective`, `transform`, `scale`, `rotate` у предка ломают
  `position: fixed`.** Нижняя полоса закладок на телефоне лежит внутри папки;
  поэтому после открытия перспектива снимается (`.revealed .folder`), а в
  режиме Снюфа на узком экране качаются листы, а не папка — и именно
  `scale: none`, а не `scale: 1`.
- **Стол — `overflow: clip`, не `hidden`**: hidden-блок браузер прокручивает
  сам, дотягиваясь до сфокусированной кнопки, и стол уезжал.
- Класс `.note` занят пометкой ручкой (`PenNote`) — у бумажки Снюфа свой
  `.snuff-note`.
- Раскладка листов — container queries по ширине листа (`.sheet` —
  `container-type: inline-size`): на развороте лист вдвое уже окна.
- Свет в режиме Снюфа пульсирует, но не мигает резко: не больше трёх
  вспышек в секунду (фоточувствительная эпилепсия). При «уменьшить движение»
  прожекторы стоят, папка не качается.
