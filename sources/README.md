# Исходники для сайта !захар

Сюда — всё сырьё. В git эта папка не пойдёт целиком (тяжёлое), на сайт попадёт
только обработанное.

| Папка | Что класть |
| --- | --- |
| `photo/it` | работа, код, офис, выступления про IT |
| `photo/event` | ты ведущий: свадьбы, деловые события, сцена, микрофон |
| `photo/sport` | спорт |
| `photo/music` | запись, студия, микрофон, обложки треков |
| `photo/life` | всё остальное открытое: романтика, «ситуации», друзья |
| `video` | ролики с мероприятий, сторис, закулисье (как есть, сожму сам) |
| `music` | два трека (!захар), сведения DJ Снюфа — mp3/wav, обложки |
| `brand` | рукописное: подпись, почерк, рисунки, фото блокнотов, любимые шрифты/референсы |
| `texts` | что угодно словами: фразы, шутки, «2 метра безобразия», цитаты, факты о себе |

Чем больше сырого и живого — тем меньше сайт похож на шаблон. Фото — в
максимальном качестве (оригиналы, не скриншоты из инстаграма).
